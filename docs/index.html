First working experiment

Educational model · Not a validated appliance prediction

Electrical → thermal coupling

An ideal fixed-voltage resistive load couples to a lumped thermal body using the existing Physics implementation. The absorbed-energy fraction is an explicit input—not a predicted efficiency. The adapter runs through the registered FSM_Execution workflow, records model and configuration provenance, and supports exact-version replay.

Break it in concept before you try it in reality.

Virtual laboratory service

Reserve a scientific capability

The long-term service model lets a researcher reserve a private virtual workspace with declared models, instruments, compute allowances, assumptions, and limitations.

Experiment campaigns

Challenge the idea

Build a baseline and deliberately probe boundaries, sensitivity, tolerances, disturbances, and supported failure scenarios. Every run keeps its exact configuration and provenance.

Evidence before reality

Know what remains unknown

Compare results, uncertainty, model fidelity, and resource use. Export the evidence and identify which questions still require qualified physical testing.

Hosted reservations, billing, tenant isolation, physical instrument operation, and the complete campaign runtime are future capabilities—not features represented as live today. A virtual result is not a safety certification or a substitute for physical validation.

What comes next

This site is the first public-facing window into the repository, not a claim that the full platform is finished. The immediate work is reusable template comparison/export, runtime resource enforcement, multi-host proof, and a game-facing laboratory adapter. Live experiment controls and result visualization will arrive as those host-facing presentation contracts are implemented.
