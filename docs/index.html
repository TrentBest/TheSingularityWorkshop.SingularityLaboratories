04 · Evidence, not theatre
Every result needs a chain of custody.
Distinguish a model declaration, a host observation, an executed run, and a reviewed scientific conclusion.


Domain contract
What the experiment declares
Experiment/model IDs and versions, parameter schema, assumptions, limitations, safety metadata, required capabilities, and immutable configuration.


Host observation
What actually happened
Composition host reports what resolved and loaded. Execution host reports what was invoked and its lifecycle. Package references prove neither.


Run provenance
What the run records
Exact versions, configuration, timestamps, outputs, errors, and replay lineage. Failed, cancelled, and not-run scenarios remain visible.


Analysis layer
What evidence supports
Compatible metric comparisons, declared uncertainty, domain limits, and acceptance evaluations with explicit not-evaluable states.


Scientific integrity: an educational model remains educational. A campaign result is not a safety certification, physical measurement, or permission to operate equipment.
